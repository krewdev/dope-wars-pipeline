# DOPE WARS: THE PIPELINE

Satirical 30-day trading game. Farmers mint plants. Chemists cook a batch. If purity clears, the batch **is** a meme token. Traffickers move it. Advertisers make it loud. Cops freeze, lock, or burn. Bridgeport is the exit.

This is a game. Recipes are item IDs + a purity roll. No real chemistry.

## Play

Open `index.html` on your phone, or after Pages is on:

https://krewdev.github.io/dope-wars-pipeline/

Enable Pages: repo **Settings → Pages → Deploy from a branch → main / root**.

## Day 1

1. FARM GREEN in Brooklyn
2. JET QUEENS
3. BUY CATALYST ×2
4. COOK GREEN + CATALYST
5. PAY HARRY

Harry is 10% a night. Vest of a certified cook locks 3 days — lift off the Coney curve and sell Manhattan or the chainsaw eats the run.

Matched recipes: GREEN+CATALYST → $PIPE · PURP+BINDER → $COAT · FROST+GLAZE → $DOCKS · DANK+CATALYST → $HARDASS · GLASS+BINDER → $PURITY · DUST+CUT → $SEIZED

## Sim vs protocol

City fills in the HTML use a **40× feel multiplier** so a $2,000 / 30-day game can service Harry. On-chain `constants.rs` is **not** 40×.
